Adaptive Book Recommendation and Rating Prediction System

Using NLP and Machine Learning

Project Overview

This project uses natural language processing and machine learning to recommend books and predict user ratings. We analyze book descriptions, features, and metadata to build a system that can help readers discover books they may enjoy.
