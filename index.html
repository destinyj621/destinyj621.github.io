Adaptive Book Recommendation and Rating Prediction System Using NLP and Machine Learning

Personalized book discovery using text features and predictive modeling

This site accompanies our research poster for the Fall 2025 Computing Showcase. The project builds an adaptive system that uses natural language processing and machine learning to recommend books and predict user ratings based on book descriptions, metadata, and reader feedback.

Project Overview
What this system is designed to do

The Adaptive Book Recommendation and Rating Prediction System combines text processing, feature engineering, and supervised learning to model how readers respond to different books. We extract information from book titles, descriptions, authors, and genres, build numerical representations with NLP techniques, then train models that can recommend new titles and estimate expected ratings for unseen books.

Project Poster
Summary of the pipeline and results
View Poster (PDF)

The poster outlines the full workflow, including data collection, preprocessing, NLP feature extraction, model selection, evaluation, and error analysis. It also highlights how recommendation quality changes with different feature sets and models and discusses future directions such as incorporating user profiles and temporal reading patterns.
