Fall 2025 Computing Showcase

Adaptive Book Recommendation and Rating Prediction System Using NLP and Machine Learning

This site accompanies our research poster for the Fall 2025 Computing Showcase. The objective of this project is to develop an adaptive system that learns a user’s reading preferences, predicts the rating they would assign to new books, and recommends additional books based on thematic similarity. The system also allows dynamic updates through ISBN-based book entries, supporting continuous learning without requiring full retraining after each addition.
